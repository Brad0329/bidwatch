# CLAUDE.md 비대화 방지 ★CLAUDE.md에는 상한이 있다

> 2026-09-26 `/doctor` 정리로 CLAUDE.md 본문에서 옮겼다 — CLAUDE.md를 읽거나 고칠 때만 실린다.
> 상한 검사는 구조로 강제된다(`tests/test_count_claude_rules.py`가 실제 CLAUDE.md로 돈다).

- **CLAUDE.md는 매 세션의 컨텍스트에 통째로 실린다** — 규칙이 많을수록 규칙별 준수율이 떨어진다.
  단위는 바이트가 아니라 **개수**다(IFScale 2025, Claude Code 세션 1,650건 요인 연구 2026).
- **상한: 규칙 100개**. 센다: `python scripts/count_claude_rules.py` —
  글머리·번호·표 행 하나 = 규칙 하나, `<...>` 플레이스홀더는 제외.
  Phase 종료 시 확인하고, 넘으면 이관한다:
  ① 구조(훅·테스트)로 강제된 항목은 한 줄+링크로 ② 정정의 역사·실험 전말은 플레이북으로
  (본문엔 현재 결론만) ③ 기능 상세는 REQUIREMENTS·Phase 로그로, 진행 서사는 plan.md로
  ④ 특정 파일·작업에서만 필요한 규칙은 이 파일처럼 `.claude/rules/*.md`(`paths` 지정)로.
  남기는 것은 **"매 작업마다 적용되는 규칙 + 다음 세션이 첫 10분에 알아야 할 것"** 뿐이다.
- **중요한 규칙은 앞에 둔다.** ① 어기면 되돌리기 비싸고 구조(훅·테스트)로 강제되지 않는 것
  ② 매 작업마다 적용되는 것 ③ 참조용은 가운데 ④ 특정 시점에 찾아 읽는 것은 끝.
- **규칙은 빼기만 한다.** 한 번 통과하면 끝나는 게이트에는 모래시계(⏳) 만료 표시를 붙이고, 조건이
  채워지면 그 문장을 지운다. 만료 대상은 `count_claude_rules.py`가 Phase 종료 점검 때 함께 출력한다.
- **덧붙일 때 나갈 것을 함께 정한다.**
