# 경쟁 서비스 조사 (2026-09-24)

> 목적: BidWatch(공공 API + 고객 지정 기관 사이트 수집 → 키워드·지역 필터 → 한 화면 + 팀 검토 태그)와
> 유사한 서비스가 어디까지 해 주는지 파악해 F-015(고객사 관리자)·F-016(운영자 콘솔)·요금제 설계에 쓴다.
>
> **한계 — 반드시 같이 읽을 것**
> - 전부 **로그인 전 공개 페이지 기준**(공식 페이지·요금 페이지를 WebFetch/curl로 1회씩). 유료 화면 안의 기능은 미확인.
> - 가격 숫자는 curl 원문 grep으로 재확인한 것만 적었다. WebFetch 요약이 비드프로 가격을 3군데 틀리게 옮긴 실사례가 있다
>   → **경쟁사 가격을 인용할 때는 원문 grep으로 다시 확인**(`curl -s -L -A "Mozilla/5.0" <URL> | sed -e 's/<[^>]*>/ /g' | grep -aE "[0-9]{2,3},[0-9]{3}|개월"`).
> - 수집 규모("300+ 채널", "60,000+ agencies" 등)는 각사 주장, 실측 아님.
> - 실존 확인 실패(검색 결과 없음): 고비드·비드맨·엔젤입찰·입찰나라·"윙크"(지원사업 알림).

## 1. 결론

1. **경쟁 구도는 세 무리**
   - ① 전통 입찰정보사: 건설·물품 **투찰가 분석**이 핵심. 월 2.7만~4.4만원 단일 상품, 1 ID. 1:1 분석(낙찰금액 1.5%)·대행을 따로 판다.
   - ② 용역·IT AI 신생 서비스(**BidWatch와 가장 직접 겹침**): GovLens·클라이원트·지투비플러스·산군·MyBidWise. 적합 공고 선별, 공고·RFP AI 요약, 일부 팀 협업.
   - ③ 지원사업 알림: 회사 프로필 기반 **적합도 0~100점 + 이유**, **카카오 알림톡**. 공공(기업마당·중기부)은 무료이고, 중기부가 AI 추천·사업계획서 초안을 무료로 추진 중이다.
2. **기본 기능(대부분 제공)**: 하루 1회 맞춤메일, 마감 D-3 리마인더, 사전규격·발주계획, 카카오 알림톡이나 앱.
   AI 공고 요약은 최저 요금제로 내려오는 추세다(해외 거의 전부, 국내 신생 서비스).
   → **BidWatch에 없는 기본 기능: 알림(메일·카카오), AI 요약.**
3. **차별 기능(일부만 제공)**
   - 자격요건 추출(지역제한·면허·실적)과 첨부 본문 검색: 클라이원트·낙비·지원받자!
   - 사전규격이 본공고로 전환되면 알림: GovLens
   - 과거 낙찰·경쟁사·발주처 분석: 국내 전통사의 핵심 상품, 해외는 상위 요금제
4. **아무도 안 하는 것(공개 페이지 기준, 국내외 약 40곳)**
   - **고객이 지정한 기관 사이트 URL을 수집 대상에 추가하는 기능.** 해외는 운영자가 소스를 고르고 고객에게는
     "데이터 추가 요청" 창구를 둔다(GovSpend는 모든 구독에 포함).
   - **팀 검토 상태 흐름 태그.** 가까운 것은 GovLens 칸반·코멘트(Enterprise, 5명), 지투비플러스 메모 공유 정도다.
5. **요금 등급을 나누는 기준**: 범위(지역·시장), 규모(사용자 수·저장검색·필터 수), 기능 모듈. AI 분석은 횟수·크레딧으로 따로 과금하는 경우가 많다.
6. **피할 영역**: 건설 투찰가 분석(전통사 장악), 제안서·사업계획서 AI 작성(클라이원트·MyBidWise·정부까지 진입한 레드오션).
   1~3인 용역·IT 팀에게는 **"놓치지 않기 + 팀 검토"** 축이 맞아 보인다.

### F-015 / F-016 / 요금제에 주는 시사점
- **F-015**: 팀 기능이 드물고 상위 요금제에 있다 → 팀원 초대·역할 관리가 1~3인 팀에 팔 만한 핵심. 등급 기준도 대부분 사용자 수.
- **F-016**: "사이트 추가 요청 접수 + 운영자 검증"이 운영자 화면의 한 축(GovSpend·Mercell·GovWin). AI 스크래퍼가 실패한 URL을 운영자가 넘겨받는 흐름과 이어진다.
- **요금제**: 국내 신생 서비스의 가격대는 월 0 / 1.5만~5만 / 10만~20만원. 사용자 수(1 → 5명)와 AI 사용 횟수로 등급을 나누는 형태가 흔하다.
