# 나라장터 밖 입찰공고 — 자체조달기관 조사 (2026-09-24)

> 목적: "나라장터에 모든 공공 입찰이 올라오는가"를 확인하고, 추가로 수집할 출처를 정한다.
> 방법: 법령은 law.go.kr DRF API 원문으로, 기관 목록은 조달청 자료로 확인했다. 나라장터 API로 2주치(2026-09-07~20, 16,499건, 호출 18회)를 실측했다.
> 실측 스크립트: `scripts/_tmp/probe_rgst.py`(gitignore).

## 1. 결론
- **모든 공공 입찰공고가 나라장터에 올라오지 않는다.** 국가기관은 나라장터 공고가 원칙이다(국가계약법 시행령 제33조①). 예외가 두 가지 있다.
  ① 부처가 지정·고시한 별도 시스템 — 한전 SRM, 국방 D2B, 학교장터 S2B, eat 급식
  ② 공공기관의 "자체전자조달시스템" — 전자조달법 제14조
- **조달청의 통합 대상은 25곳이고, 2025-11-17 기준 12곳이 나라장터로 통합됐다.**
  남은 곳 중 한전·LH·수자원공사·도로공사·가스공사·국가철도공단·한수원·방위사업청은 나라장터 API에 공고가 **0~3건**뿐이다(2주).
- **나라장터 API는 자체조달 공고를 연계해 주지 않는다.** 16,499건 전부 `rgstTyNm` = "조달청 또는 나라장터 자체 공고건"이었다.
  조달청은 "연계 공고를 제공한다"고 설명하지만 이 API에서는 확인되지 않았다 → 기관별로 따로 받아야 한다.
- 지투비플러스가 내세우는 "25개 자체조달기관"은 조달청 통합 대상 수(25)와 숫자만 같다. 명단이 공개돼 있지 않아 대조하지 못했다.

### 3-1. 알리오(ALIO) — 자체조달기관을 한 곳에서 받을 후보 (2026-09-24 추가 실측)
- `alio.go.kr/occasional/bidList.do`는 Vue 화면이고, 데이터는 **공개 JSON API** `GET /occasional/findBidList.json?type=title&word=&pageNo=N&area=`
  (인증 없음, 10건/페이지)에서 온다. 필드: `rtitle`(제목) `pname`(기관) `bdate`(공고일 `YYYY.MM.DD`) `bidInfoEndDt`(마감일)
  `seq`(상세 `/occasional/bidDtl.do?seq=`). 전체 83,801건, 최근 100건 = 공고일 이틀치(하루 약 50건 → 5페이지).
- **나라장터와 대조**(최근 100건, 제목 공백 무시 정확 일치, 우리 DB nara 4,698건): **58건 겹침, 42건 알리오에만.**
  알리오에만 있는 42건: 한국공항공사 12(대부분 자산 **매각**) · **한국수자원공사 12 · 한국철도공사 7** · 한국보훈복지의료공단 2 ·
  **한국전력공사 2** · **LH 1** · 기타. → 위 표에서 "기관별로 따로 받아야 한다"던 자체조달 공기업이 알리오에 들어 있다.
- 한계: 표본 100건(이틀) · 정확 일치라 겹침은 과소 추정일 수 있음 · 매각 공고가 섞인다 · 자체조달기관이 알리오에 **전부** 올리는지는 미확인.
- lets_portal 손 설정의 "신용보증기금" 항목은 실제로 이 알리오 전체 게시판을 가리키고 있었다(이름 오류).

## 4. 미확인
- 조달청 통합 대상 25곳의 정확한 명단. "미통합"은 2017년 목록 26곳에서 통합된 12곳을 뺀 **추정**이다(조달청 전자조달통합과에 문의하거나 정보공개청구가 필요).
- 기관별 API의 실제 응답과 활용신청 필요 여부.
- 조달데이터허브 "자체전자조달시스템 입찰공고 내역"(15159273) — SSO 벽에 막혀 열지 못했다.
- 교육청의 S2B 적용 여부, 민간위탁·보조사업 공모·사립대 입찰의 계약법 적용 여부.
- 연계 공고 0건은 PPSSrch 오퍼레이션, 2주 기준이다.
